SoloMD v5.4.0 带来全面工作流升级与同步稳定性强化：

• 代码片段面板与 :::alert-* 提示块：新增右侧栏「代码片段」管理面板，支持 %% 选中包裹、@@ 光标定位、19 个内置变量及最近使用置顶，同时原生渲染 :::alert-info/warning/danger/success 提示块。
• 浏览器风格标签组：支持彩色可折叠标签组、拖拽入组，以及打开文件时按目录/后缀自动打开同路径文件。
• 自定义工具栏全命令扩展：支持将命令面板中的任意命令固定到工具栏，提供分类筛选、搜索与 20 款图标自定义。
• 设置「基础」6 分页重构：拆分为基础与外观、字体与排版、编辑器、渲染与预览、布局、导航栏，支持跨页签搜索。
• VS Code 快捷键一键预设：一键将 Ctrl/Cmd+Shift+P 设为命令面板、Ctrl/Cmd+B 设为加粗。
• 多端云同步增强：联网恢复自动同步、同步文件树排序与手动顺序、本机 UUID 防覆盖日志。
• 修复实时模式下 LaTeX $$ 公式块回车后中文输入卡顿，优化窗口位置恢复无跳动，扩展 Codex CLI / DSH / OpenCode MCP 支持。
