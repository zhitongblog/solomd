SoloMD 5.0.17 更新：
• 同步設定左側二級分類導航樹與獨立子頁面（#524）：在「設定 › 同步」左側導航欄下展開二級分類樹（Git 同步 / 網盤直連 API / 本地網盤目錄 / WebDAV 同步 / 歷史版本快照），每個同步分支獨立渲染專屬設定頁面。
• WebDAV 與網盤同步介面精簡及加密口令二次確認（#525）：將勾選項精簡為雙列緊湊佈局並配懸停說明；未勾選啟用時自動置灰鎖定下方設定；新增 WebDAV 伺服器類型預設下拉選單（堅果雲、Nextcloud、AList、自訂 WebDAV）；全面增加「確認加密口令」二次校驗、不一致紅框攔截及防遺忘警示框。
• 游標位置歷史佇列與前進/後退快捷鍵（#491）：編輯器按分頁維護容量為 10 的游標跳轉歷史佇列，支援透過 Alt + 左方向鍵 與 Alt + 右方向鍵 在歷史編輯位置間快速前後跳轉。
• 快速記錄視窗非同步喚起與穩定性加固：修復快速記錄選單喚起阻塞及收件匣標記即時儲存。
