SoloMD 5.0 — 더 차분하게 글을 쓰는 곳.

• 새롭게 디자인한 창: 간결한 헤더에서 실시간 / 소스 / 분할 / 미리보기를 한 번에 전환하고, 폴더와 노트를 위한 사이드바, 알약 모양의 탭, 상태 막대 대신 작은 단어 수 표시를 제공합니다.
• iPhone: 노트 홈 화면, 하단의 검색과 새 노트 버튼, 전체 화면 편집기.
• iPad: 세로 방향에서는 사이드바가 페이지를 좁히지 않고 위로 겹쳐 나타납니다.
• 새로운 찾기 막대: 방해가 되지 않고, 위치를 유지하며, 대소문자 구분, 전체 단어, 정규 표현식을 지원합니다.
• 텍스트를 선택하면 서식 버블이 나타나고, iPhone과 iPad에서는 키보드 위 막대에서 제목, 목록, 링크, 코드를 추가할 수 있습니다.
• 여백에서 제목을 접어 긴 문서의 구조를 한눈에 볼 수 있습니다.
• 메뉴와 단축키를 재정리했습니다. 모든 단축키를 다시 지정할 수 있으며, iPad에서는 단축키에 ⌘가 표시됩니다.
• 더 빠른 첫 화면: 수식과 코드 강조는 페이지가 나타난 뒤에 불러옵니다.
• 중국어 교정에서 文档.md 같은 파일 이름이나 말줄임표를 더 이상 문장 부호 오류로 표시하지 않습니다.
