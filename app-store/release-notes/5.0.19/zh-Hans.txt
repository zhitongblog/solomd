SoloMD 5.0.19 更新：
• 独立图表源码折叠开关与按需展开：新增「渲染并折叠表格、Mermaid 等图表源码」独立开关，与「始终显示 Markdown 标记」解耦；保留行内标记避免标题/列表点击跳动的同时，表格与 Mermaid 保持渲染并支持右上角「源码」一键展开或折叠。
• Windows 表格渲染与大纲面板增强（#124）：修复 CRLF 换行、列表缩进及引用块内表格渲染，修复分块编辑器点击标题行高跳动；大纲面板新增一键「全部展开 / 全部折叠」与长标题自动折行开关。
• 笔记模板系统（#285）：内置会议记录、读书笔记、周报、项目规划等 5 套模板，支持读取工作区 templates/ 目录及 {{date}}、{{time}}、{{title}} 动态变量替换。
• 分屏悬停同步高亮与阅读页宽切换（#377, #145）：分屏模式悬停自动高亮对侧对应源码行；阅读视图底部新增 600px / 760px / 960px / 100% 页宽切换胶囊。
• 全库标签重命名、文件树多选与防打断自动提交（#397, #380, #129, #530, #322, #208, #492, #479）：支持右键重命名/删除全库标签、文件树多选批量操作、全局搜索路径与时间筛选、全屏顶部悬停呼出工具栏及 Git 空闲防抖自动提交。
