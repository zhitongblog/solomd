SoloMD 5.0.19 更新：
• 獨立圖表原始碼摺疊開關與按需展開：新增「渲染並摺疊表格、Mermaid 等圖表原始碼」獨立開關，與「始終顯示 Markdown 標記」解耦；保留行內標記避免標題/列表點擊跳動的同時，表格與 Mermaid 保持渲染並支援右上角「原始碼」一鍵展開或摺疊。
• Windows 表格渲染與大綱面板增強（#124）：修復 CRLF 換行、列表縮排及引用區塊內表格渲染，修復分塊編輯器點擊標題行高跳動；大綱面板新增一鍵「全部展開 / 全部摺疊」與長標題自動換行開關。
• 筆記範本系統（#285）：內建會議記錄、讀書筆記、週報、專案規劃等 5 套範本，支援讀取工作區 templates/ 目錄及 {{date}}、{{time}}、{{title}} 動態變數替換。
• 分屏懸停同步高亮與閱讀頁寬切換（#377, #145）：分屏模式懸停自動高亮對側對應原始碼行；閱讀視圖底部新增 600px / 760px / 960px / 100% 頁寬切換膠囊。
• 全庫標籤重新命名、檔案樹多選與防打斷自動提交（#397, #380, #129, #530, #322, #208, #492, #479）：支援右鍵重新命名/刪除全庫標籤、檔案樹多選批次操作、全域搜尋路徑與時間篩選、全螢幕頂部懸停呼出工具列及 Git 閒置防抖自動提交。
