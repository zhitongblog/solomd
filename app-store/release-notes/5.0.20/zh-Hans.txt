SoloMD 5.0.20 更新：
• 自定义导出与文件夹批量导出（#535, #359）：新增「自定义导出 / 批量导出…」对话框，支持将当前笔记或整个文件夹（含子目录）一键导出为 PDF、HTML、DOCX 或 PNG，自动记忆上次导出目录并提供一键打开输出文件夹按钮。
• 笔记库管理与精准同步防护（#531）：同步设置新增「笔记库管理」页签，支持注册专属同步笔记库；保存桌面/下载目录等外部临时文件或浏览非注册目录时绝不误触发同步，保存已纳管笔记库内文档时自动定位所属库同步。
• Mermaid / PlantUML 手动折叠与零跳动标记（#530, #536）：实时编辑模式下图表源码默认折叠，光标上下移动经过围栏边界不再自动展开源码，仅在点击右上角「+ / 源码」按钮时手动展开；开启「始终显示 Markdown 语法标记」时全平台所有行点击零跳动。
• 实时模式行号、表格等高与代码块体验优化（#532, #533, #534, #537）：支持 Windows 实时模式显示行号；修复空表格行与有文字表格行高度不一致问题；自定义 CSS 选择器默认定位至 themes 目录；修复 /code 插入代码块光标落位及首行非语言文字被吞问题。
