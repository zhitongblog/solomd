SoloMD 5.0.20 更新：
• 自訂匯出與資料夾批次匯出（#535, #359）：新增「自訂匯出 / 批次匯出…」對話框，支援將目前筆記或整個資料夾（含子目錄）一鍵匯出為 PDF、HTML、DOCX 或 PNG，自動記憶上次匯出目錄並提供一鍵打開輸出資料夾按鈕。
• 筆記庫管理與精準同步防護（#531）：同步設定新增「筆記庫管理」頁籤，支援註冊專屬同步筆記庫；儲存外部臨時檔案或瀏覽非註冊目錄時絕不誤觸發同步。
• Mermaid / PlantUML 手動摺疊與零跳動標記（#530, #536）：即時編輯模式下圖表原始碼預設摺疊，游標移動經過圍欄邊界不再自動展開，僅在點擊「+ / 原始碼」按鈕時手動展開；開啟「始終顯示 Markdown 語法標記」時全平台點擊零跳動。
• 即時模式行號、表格等高與程式碼區塊體驗優化（#532, #533, #534, #537）：支援 Windows 即時模式顯示行號；修復空表格列與有文字表格列高度不一致問題；自訂 CSS 預設打開 themes 目錄；修復 /code 插入程式碼區塊游標落位問題。
