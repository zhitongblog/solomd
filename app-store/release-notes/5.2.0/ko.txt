SoloMD 5.2.0:
• 통합 내보내기 센터 (#566, #572): 단일 노트와 폴더 내보내기를 9가지 형식(PDF, HTML, Word .docx, EPUB, ODT, LaTeX, RTF, PNG, TextBundle)으로 통합하고, 북마크/검색 사이드바 및 첫 페이지 목차(페이지 번호 포함) 옵션을 일원화했으며 다중 페이지 PDF 목차 페이지네이션을 개선했습니다.
• 순수 WYSIWYG 편집 모드 (#303): 커서가 있는 활성 줄에서도 제목, 굵게, 링크, 인라인 이미지의 Markdown 기호를 숨겨 깜빡임 없이 편집할 수 있습니다.
• 로컬 AI 자동 탐색 및 경량 확장 (#173, #286): Ollama, LM Studio, vLLM, llama.cpp, Jan 로컬 서버 원클릭 OPR 탐색과 / 슬래시 템플릿, 텍스트 변환, 웹훅을 위한 JSON 확장(.solomd/plugins/*.json)을 지원합니다.
• 수식 렌더링 개선 (#573): 연속된 줄에서 인라인 분수(\dfrac / \frac)가 위아래로 겹치던 문제를 수정했습니다.
