SoloMD 是一款安静、轻快的 Mac Markdown 编辑器。打开就能写——不用注册，没有账号，没有订阅。

笔记就是你自选文件夹里的普通 .md 和 .txt 文件。直接打开你已经在用的文件夹，原地编辑。任何平台上的任何编辑器都能打开，十年后依然可读。

写作优先

- 实时编辑：光标离开这一行，Markdown 标记就自动收起，眼前是文章而不是符号。
- 真正的排版：标题够大、粗体够粗、代码等宽、行宽舒适。
- 四种视图一键切换：实时、源码、分栏（同步滚动）、预览。
- 专注模式只亮当前段落；打字机模式让正在写的那一行始终停在视线高度。
- 选中文字弹出格式气泡。
- 查找与替换，支持区分大小写、全词匹配和正则表达式。
- 浅色 / 深色主题，跟随 Mac 外观。

地道的 Mac 应用

- 安静的窗口：侧栏里是文件夹和笔记，多标签，各种面板不叫不出来。
- 原生菜单，几乎每个操作都有快捷键——每一个都能改绑。
- 命令面板与快速切换。
- 双击任意 .md / .txt 文件直接打开；支持多窗口。
- 体积小、启动快，Apple 芯片与 Intel 原生运行。

更强的 Markdown

- KaTeX 数学公式，行内与块级。
- Mermaid 流程图、时序图、甘特图。
- 表格（附可视化表格编辑器）、任务清单、脚注、Front Matter、高亮。
- 13 种以上语言的代码高亮。
- 标题可折叠，长文档结构一目了然。
- 大纲、[[双链]]反向链接、整个文件夹全文搜索。

为中文写作而做

- 简繁转换、拼音、按中文习惯统计字数。
- 中文校对：半角标点、常见笔误一键检查。
- UTF-8、UTF-16、GBK、Big5 编码的老文件都能正确打开。

导出

- PDF，文字可选中，公式和图表一并渲染。
- Word（.docx），表格保留，可套用你自己的模板。
- HTML，或复制为 HTML / 纯文本 / Markdown。

隐私从设计开始

SoloMD 不收集任何数据。没有账号、没有统计、没有广告、没有跟踪。笔记只在你自己的文件里。
