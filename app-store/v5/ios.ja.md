SoloMD は、iPhone と iPad のための静かで軽快な Markdown エディタです。アプリを開けば、すぐに書き始められます。アカウントも登録もサブスクリプションも必要ありません。

ノートはふつうの .md と .txt ファイルです。「ファイル」App の SoloMD フォルダに置くことも、いつも使っているフォルダを開いてその場で編集することもできます。どのデバイスのどのエディタでも読めるので、今日も十年後も変わらず開けます。

書くことを第一に

- ライブ編集：カーソルが行を離れると Markdown の記号は控えめに隠れ、構文ではなく文章そのものが見えます。
- 本格的な組版：大きな見出し、しっかりした太字、等幅のコード、読みやすい行の長さ。
- フォーカスモードは今いる段落以外を薄く表示し、タイプライターモードは書いている行を目の高さに保ちます。
- テキストを選択すると書式バブルが表示され、キーボードバーから見出し、リスト、リンク、コードをワンタップで入力できます。
- 検索と置換は、大文字と小文字の区別、単語単位の一致、正規表現に対応しています。
- システム設定に合わせて切り替わるライトテーマとダークテーマ。

iPhone では

- ノートのホーム画面、検索、新規ノートボタンを親指の届く位置に配置。
- シンプルなナビゲーションバーを備えたフルスクリーンのエディタ。

iPad では

- フォルダとノートを並べたサイドバー、タブ、表示中の書類のアウトライン。
- Split View と Slide Over に対応。ハードウェアキーボードと ⌘ ショートカットも使えます。

さらに広がる Markdown

- KaTeX による数式を、インラインとディスプレイの両方で。
- Mermaid のフローチャート、シーケンス図、ガントチャート。
- 表、タップでチェックできるタスクリスト、脚注、フロントマター、ハイライト。
- 13 以上の言語に対応したシンタックスハイライト。
- 画像や図をタップするとフルスクリーンで表示し、ピンチで拡大できます。
- 見出しを折りたたんで、長い書類の全体像をつかめます。

中国語で書く人のために

- 簡体字と繁体字の相互変換、ピンイン、CJK に配慮した文字数カウント。
- 半角句読点やよくある誤記をチェックする中国語の校正機能。
- UTF-8、UTF-16、GBK、Big5 のファイルを正しく開けます。

書き出しと共有

- 数式と図をレンダリングした PDF。
- 表を保持した Word (.docx)。
- HTML のほか、HTML、プレーンテキスト、Markdown としてコピー。

設計からプライバシーを守る

SoloMD はデータを一切収集しません。アカウントも、解析も、広告も、トラッキングもありません。ノートはあなた自身のファイルの中にとどまります。
