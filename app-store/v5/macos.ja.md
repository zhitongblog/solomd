SoloMD は、Mac のための静かで軽快な Markdown エディタです。アプリを開けば、すぐに書き始められます。アカウントも登録もサブスクリプションも必要ありません。

ノートは、あなたが選んだフォルダにあるふつうの .md と .txt ファイルです。いつも使っているフォルダを開いて、その場でファイルを編集できます。どのプラットフォームのどのエディタでも読めるので、今日も十年後も変わらず開けます。

書くことを第一に

- ライブ編集：カーソルが行を離れると Markdown の記号は控えめに隠れ、構文ではなく文章そのものが見えます。
- 本格的な組版：大きな見出し、しっかりした太字、等幅のコード、読みやすい行の長さ。
- ワンクリックで切り替えられる 4 つの表示：ライブ、ソース、スクロールが同期する分割表示、プレビュー。
- フォーカスモードは今いる段落以外を薄く表示し、タイプライターモードは書いている行を目の高さに保ちます。
- テキストを選択すると書式バブルが表示されます。
- 検索と置換は、大文字と小文字の区別、単語単位の一致、正規表現に対応しています。
- Mac の外観に合わせて切り替わるライトテーマとダークテーマ。

Mac のアプリとして

- 静かなウインドウ：フォルダとノートのサイドバー、タブ、そして呼び出すまで表に出てこないパネル。
- ほぼすべての操作にショートカットがあるネイティブメニュー。どのショートカットも割り当て直せます。
- コマンドパレットとクイックスイッチャー。
- .md や .txt ファイルをダブルクリックするだけで開けます。複数ウインドウに対応。
- 小さなダウンロードサイズ、すばやい起動、Apple Silicon と Intel にネイティブ対応。

さらに広がる Markdown

- KaTeX による数式を、インラインとディスプレイの両方で。
- Mermaid のフローチャート、シーケンス図、ガントチャート。
- ビジュアルな表エディタ付きの表、タスクリスト、脚注、フロントマター、ハイライト。
- 13 以上の言語に対応したシンタックスハイライト。
- 見出しを折りたたんで、長い書類の全体像をつかめます。
- アウトライン、[[wiki リンク]] のバックリンク、フォルダ全体の検索。

中国語で書く人のために

- 簡体字と繁体字の相互変換、ピンイン、CJK に配慮した文字数カウント。
- 半角句読点やよくある誤記をチェックする中国語の校正機能。
- UTF-8、UTF-16、GBK、Big5 のファイルを正しく開けます。

書き出し

- テキストを選択でき、数式と図をレンダリングした PDF。
- 表を保持した Word (.docx)。自分のテンプレートを使うこともできます。
- HTML のほか、HTML、プレーンテキスト、Markdown としてコピー。

設計からプライバシーを守る

SoloMD はデータを一切収集しません。アカウントも、解析も、広告も、トラッキングもありません。ノートはあなた自身のファイルの中にとどまります。
