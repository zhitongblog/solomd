SoloMD — спокойный и быстрый редактор Markdown для Mac. Откройте приложение — и вы уже пишете: без аккаунта, без регистрации, без подписки.

Ваши заметки — обычные файлы .md и .txt в папках, которые вы выбираете сами. Откройте папку, которой уже пользуетесь, и редактируйте файлы прямо там, где они лежат. Их прочитает любой редактор на любой платформе — сегодня и через десять лет.

ГЛАВНОЕ — ТЕКСТ

- Живое редактирование: разметка Markdown убирается, как только курсор покидает строку, — вы видите документ, а не синтаксис.
- Настоящая типографика: крупные заголовки, честный полужирный, моноширинный код, удобная длина строки.
- Четыре вида в один клик: живой, исходный код, разделённый с синхронной прокруткой и предпросмотр.
- Режим фокуса приглушает всё, кроме текущего абзаца; режим пишущей машинки держит вашу строку на уровне глаз.
- Над выделенным текстом появляется панель форматирования.
- Поиск и замена с учётом регистра, по целым словам и с регулярными выражениями.
- Светлая и тёмная темы, которые следуют за оформлением Mac.

ПРИЛОЖЕНИЕ ДЛЯ MAC

- Тихое окно: боковая панель с папками и заметками, вкладки и панели, которые не мешают, пока вы их не вызовете.
- Нативные меню с сочетанием клавиш почти для всего — и любое из них можно переназначить.
- Палитра команд и быстрый переход.
- Двойной щелчок по любому файлу .md или .txt открывает его. Несколько окон.
- Небольшой размер, быстрый запуск, нативная работа на Apple Silicon и Intel.

MARKDOWN С ЗАПАСОМ

- Формулы KaTeX — в строке и отдельным блоком.
- Блок-схемы, диаграммы последовательностей и диаграммы Ганта на Mermaid.
- Таблицы с визуальным редактором таблиц, списки задач, сноски, front matter, выделение.
- Подсветка синтаксиса для 13+ языков.
- Сворачивайте заголовки, чтобы видеть структуру длинного документа.
- Оглавление, обратные ссылки для [[вики-ссылок]] и поиск по всей папке.

ДЛЯ ТЕХ, КТО ПИШЕТ ПО-КИТАЙСКИ

- Преобразование упрощённых ↔ традиционных иероглифов, пиньинь и подсчёт слов с учётом CJK.
- Китайская корректура: полуширинная пунктуация и частые опечатки.
- Правильно открывает файлы в UTF-8, UTF-16, GBK и Big5.

ЭКСПОРТ

- PDF с выделяемым текстом, отрисованными формулами и диаграммами.
- Word (.docx) с сохранением таблиц, при желании — по вашему собственному шаблону.
- HTML или копирование как HTML, обычный текст или Markdown.

ПРИВАТНОСТЬ ПО УМОЛЧАНИЮ

SoloMD не собирает никаких данных. Ни аккаунта, ни аналитики, ни рекламы, ни отслеживания. Ваши заметки остаются в ваших собственных файлах.
