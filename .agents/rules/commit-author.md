# Git Commit Co-Author Rule

Whenever creating a Git commit in this repository, **always** include Antigravity as a co-author trailer at the end of the commit message:

```text
Co-Authored-By: Antigravity <lixd220@gmail.com>
```

Never use `Co-Authored-By: Claude ...` in commit messages.
