SoloMD 是一款安静、轻快、本地优先的跨平台 Markdown 编辑器（支持 Android、Windows、macOS、Linux 与 iOS）。打开即写——无需注册、没有账号、没有订阅。

你的笔记始终是保存在本地文件夹中的纯文本 .md 与 .txt 文件，可直接打开任意本地目录或配合 Syncthing、WebDAV、Git 等工具多端同步。

写作优先
- 实时所见即所得编辑：光标离开当前行后自动收起 Markdown 语法符号，呈现干净排版。
- 专注模式高亮当前段落，打字机模式让光标行保持在视线中央。
- 快捷格式栏一键插入标题、列表、链接、表格与代码块。
- 极速文档内查找替换（区分大小写、全词匹配、正则表达式）与全局全文搜索。
- 浅色 / 深色主题自动跟随系统。

手机与平板体验
- 手机端单手友好的笔记列表、快速搜索与新建按钮。
- 平板端完整文件夹侧栏、多标签页、分屏与实时文档大纲，支持外接键盘快捷键。

强大的扩展语法与工具
- 支持 [[双链]]（重命名或移动文件自动更新引用）、反向链接与标签管理。
- 原生支持 KaTeX 数学公式、Mermaid 流程图/时序图/甘特图、GFM 表格、可勾选任务列表、脚注与代码高亮。
- 可选接入本地 AI（Ollama、LM Studio 等）或自带 API Key（BYOK），不配置则完全不联网。
- 支持简繁转换、拼音标注、中日韩字数统计及 UTF-8 / GBK / Big5 编码识别。
- 支持导出含目录、数学公式与图表的独立 HTML、PDF 与 Word (.docx)。
